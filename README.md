# Shari3ahSurveys

موقع عربي ثابت بعنوان: `ساحة الاستطلاعات والآراء لبرامج كلية الشريعة`.

الفكرة:
- تنظيم الاستطلاعات بما يخدم الدراسة الذاتية والاعتماد البرامجي.
- التبويب بحسب محاور الاستفادة في الدراسة الذاتية، لا بحسب الجهة فقط.
- دعم فلترة البرنامج والسنة من الواجهة.

الملفات:
- `index.html`
- `css/style.css`
- `js/app.js`
- `js/surveys-data.js`
- `scripts/build_survey_data.py`
- `استطلاعات_وتقييمات_كلية_الشريعة_1445_1446.xlsx`
- `data/graduate-samples/نتائج استطلاعات البكالوريوس.xlsx`
- `data/graduate-samples/نتائج استطلاعات الدراسات العليا.xlsx`

التشغيل:
- افتح `index.html` مباشرة.
- أو اربطه لاحقًا مع GitHub وNetlify بوصفه موقعًا static.

تحديث البيانات:
- ملف Excel الحالي هو المصدر الرسمي للبيانات.
- لتجديد بيانات الموقع بعد تحديث الملف شغّل:

```bash
python3 scripts/build_survey_data.py
```

- هذا الأمر يعيد توليد الملف `js/surveys-data.js` تلقائيًا من ملف Excel.

استطلاعات الخريجين:
- تُحفظ نتائج البكالوريوس والدراسات العليا بوصفها **استطلاعات عينة** مع عدد الاستجابات لكل نتيجة.
- لا تُستخدم عينة الخريجين بدل استطلاع تقويم البرنامج الأصلي، ولا يُستورد منها تقييم جودة البرنامج.
- البكالوريوس يكمل مؤشرات أداء الطالب، والتوظيف أو الالتحاق بالدراسات العليا، وتقويم جهات التوظيف.
- الدراسات العليا تكمل مؤشرات جودة الإشراف العلمي، وتقويم جهات التوظيف، والرضا عن الخدمات.
- الاستطلاعات الأصلية الأخرى تبقى بلا وسم إضافي؛ لا يظهر لها وصف «استطلاع شامل».
