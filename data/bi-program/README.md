# تصديرات منصة ذكاء الأعمال المفصلة بالبرنامج

ضع هنا أي ملف `.xlsx` لاستطلاعات الطلاب مصدَّرًا **على مستوى البرنامج** بصيغة ملف
`استطلاعات_وتقييمات_كلية_الشريعة_1445_1446.xlsx` نفسها، ثم شغّل:

```
python3 scripts/build_survey_data.py
```

الأعمدة المطلوبة (تُطابق بالاسم، ولا يهم ترتيبها):
الفصل الدراسي، الجنس، الدرجة العلمية، البرنامج (أو التخصص)، التقييم (اسم الاستطلاع)،
وصف الموضوع، وصف العبارة، وأعداد الإجابات: لا أوافق بشدة، لا أوافق، أوافق الى حد ما، أوافق، أوافق بشدة.
الأعمدة الاختيارية: المقر، الكلية، رقم العبارة.

متى وُجدت بيانات برنامج لسنة ما في هذه الملفات، تُترك بيانات الكلية المجمعة (مثل `data/bi-1447/`)
لذلك البرنامج في تلك السنة، فلا تختلط القيم. لا يلزم أي تعديل في الشيفرة.
